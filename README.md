# agm2027.41.is

A temporary forwarder: GitHub Pages serves `agm2027.41.is` over HTTPS and sends visitors to the 2027 annual general meeting (AGM) page,
`https://app-41is-demo-f5jkgo.azurewebsites.net/vidburdir/agm2027`, keeping the rest of the address. It stands in until the portal's App Service plan can carry
custom domains itself (Basic tier), after which the DNS record moves there and this repository is deleted.
